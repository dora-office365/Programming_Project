Instructions
1. Run the "dashboard.py" file to start the Careflow Hospital Inpatient Management System.
2. Log in using the default administrator account:
   - Username: admin
   - Password: admin123
3. After successful login, users can access and navigate between the different modules using the navigation menu.


Functions of Each Module
1. dashboard.py: Connects all the other modules, manages user authentication and navigation between pages, and displays an overview of hospital statistics and patient records.

2. patient.py: Handles patient registration, patient record management, bed assignment and patient readmission.

3. bed_management.py: Manages hospital bed availability, occupancy status and patient-bed allocation information.

4. discharge.py: Handles patient discharge, payment confirmation, discharge record updates and the release of occupied beds.

5. data.py: Manages the storage, retrieval, updating and saving of hospital records using a shared JSON database.
