Instructions
1.Run the dashboard.py to start the program
2.In the main.py file, login using the default account (username: admin ; password: admin123)
3.After login, the program can be run freely.


Function for each module:
1. dashboard.py: Links all other.py file, manages user login, navigation between modules, and displays an overview of hospital statistics and patient records.
2. patient.py: Runs the patient page to handles patient registration, record management, bed assignment, and patient readmission.
3. bed_management.py: Runs bed management page to manages hospital bed availability, occupancy status, and patient-bed allocation information.
4. discharge.py: Runs discharge page to handles patient discharge, payment confirmation, discharge record updates, and bed release.
5. data.py: Manages the storage, retrieval, updating, and saving of hospital records using a shared JSON file.
